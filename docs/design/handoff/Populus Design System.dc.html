01 — Principles

Every visual decision tells the reader something true about the data

1 · Uncertainty is content, not chrome
A range, a lag, a truncation, an ambiguity — each has one fixed rendering (§3). If a mockup looks cleaner because a caveat disappeared, the mockup is wrong.
2 · No fake precision, ever
No midpoints, no point-value bars from bucketed data, no sparklines implying trends the disclosure regime cannot support, no smoothing across gaps.
3 · Receipts within one gesture
Every row ends at the government document it came from. Every aggregate names its derivation. Every page carries the build it was rendered from.
4 · Court-record gravitas, terminal ergonomics
Serif for identity and argument; grotesque tabular figures for data; mono for identifiers and receipts. Density is respect for the analyst — hairlines, not boxes.
5 · Politically dead-neutral
Party renders in matched low-chroma duotones (§2) — identical lightness and chroma, hue only. The site never reads red-team/blue-team.
6 · Honest absence
Empty, withheld, and unparsed states say specifically what is missing, why, and where the primary source is — never a spinner, never a shrug.

05 — The uncertainty grammar

How much should I trust this number?

Seven reusable patterns. Each maps one shape of doubt to one fixed rendering, used identically across congressional trades, 13F holdings, financials, and macro. An analyst who learns the grammar once reads every module correctly.
G1 · RANGE
A bounded interval, never a number
Congressional amounts exist only as statutory buckets. Render the range band: a fixed log-scale track ($1K → $50M+) with the bucket filled. Full bounds in text at first mention; compact bounds in dense cells. Never a midpoint, an average, or a bar length pretending to be a value. Sums of ranges are themselves ranges: "$3.2M – $11.5M".

G2 · STALENESS
Two dates, one visible lag
Every trade shows traded and filed, plus the lag as "+Nd". Within the statutory 45 days: quiet gray. Beyond: an amber LATE chip. Filed is never presented as traded. Dataset-level staleness renders as an as-of stamp in every table header and a freshness badge in the page header. 13F: "holdings as of quarter-end, filed +Nd" — never "current holdings".

G3 · TRUNCATION
The list ends because the source ends
Source-truncated lists (SEC's top-25 holders per issuer) terminate in a dashed terminus row naming the truncation and its author. Never "show more", never a count implying completeness. The same terminus row pattern marks our own budget cuts ("pre-rendered top 500; rest served client-side") — always attributed.

G4 · UNDISCLOSED / UNCLASSIFIABLE
Hatching means the record itself is silent
A 45° hatch pattern is reserved for values the source did not disclose: a QoQ change with one side undisclosed renders an n/c (not classifiable) pill — never coerced into "add" or "trim" — and is excluded from net-flow charts with a visible excluded-count. Hatched chart segments show where aggregates rest on undisclosed inputs.
n/c change kind not classifiable — value undisclosed on one side · flag: change_kind_undeterminable
net-flow strip: adds · undisclosed · trims — hatched share stated in the caption
— an em-dash cell is absence in the source; it is never zero. Zero prints as 0.
G5 · INFERENCE
Dotted underline = we derived this; footnote says how
Values Populus computed or matched — issuer names from CUSIP prefixes, filer-to-member joins, estimate portfolios, "exit" classifications — carry a dotted underline and an editorial footnote marker (†, ‡, §) resolving to one compact line under the table. The dagger system replaces tooltips: it prints, it's keyboard-reachable, it never hides.
NVIDIA Corp†  ·  exit‡  ·  est. portfolio value§
† issuer name inferred from CUSIP-6 prefix, not stated in the filing issuer_from_cusip6
‡ "exit" = position absent next quarter: sold, delisted, confidential treatment, or moved to an affiliated filer — the filing does not say which
§ estimate — flow-based reconstruction from disclosed ranges; not a statement of holdings
G6 · FLAGS — two honesty classes
Solid = the source says so. Dashed = we couldn't fully read it.
The pipeline's flag taxonomy is two disjoint sets, and the UI keeps them visually disjoint. Source facts (solid tag): a property of the filing. Parse defects (dashed tag): our extraction fell short — our imperfection, published. Tags use the flag's plain-English name; the machine name is one hover away and printed on the methodology page.
source facts no ticker spouse cap amendment pending date anomaly
parse defects amount unparsed needs OCR text fallback unjoined filer
amendment_unresolved is the one amber source-fact: the number may change under settled amendment semantics (§9.5)
G7 · PROVENANCE
The receipt column
Every table's final column is SRC: a mono link naming the government system and opening the exact document (PDF page / eFD filing / EDGAR accession). Aggregates carry a "derived" link to their derivation note. Page footers carry the build ID. One convention, everywhere — the reader stops noticing it and starts trusting it.

Rules
Real <table> semantics with th scope in production. Sort affordance on headers; default sort = filed date desc (what's newly public), never traded date (which implies currency). Wide tables scroll inside their container with sticky first column — never the page.
Watchlist
Star toggle on member/ticker rows and entity headers. localStorage only — the affordance carries the label "saved on this device" the first time it's used. No account required; a future paid sync/alerts tier must not gate the free site.
Mobile collapse
Below 720px each row folds to a two-line card: line 1 member · ticker · side; line 2 range band · dual dates · flags. Same grammar, same order, ≥44px tap target opening the row detail.

Charts inherit the grammar or don't ship

bounds are sums of statutory buckets · bar = [min, max], never a point

The seven chart rules
C1 — Bucketed data draws as bands/ribbons, never lines or points.
C2 — Gaps stay gaps: no interpolation or smoothing across undisclosed periods.
C3 — Value axes start at zero, or carry an explicit break marker.
C4 — Every chart prints: source line, as-of stamp, n, and its exclusions.
C5 — Party series: duotone strokes + distinct dash patterns (never fills).
C6 — No sparklines on range data; the inline unit is the range band (G1).
C7 — Revised series (M4) show the prior vintage as a ghost stroke, labeled.
